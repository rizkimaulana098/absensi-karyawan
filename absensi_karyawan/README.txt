APLIKASI ABSENSI KARYAWAN — PHP, MySQL, Bootstrap

Instalasi:
1. Extract folder ini ke C:\xampp\htdocs\absensi_karyawan
2. Jalankan Apache dan MySQL di XAMPP.
3. Buka phpMyAdmin lalu import database.sql.
4. Buka http://localhost/absensi_karyawan/buat_admin.php
5. Setelah admin dibuat, hapus buat_admin.php.
6. Login: http://localhost/absensi_karyawan/login.php
   Username admin, password admin123.
7. Tambahkan data karyawan, lalu buat akun karyawan dari menu Akun Karyawan.

Catatan: proyek ini adalah kerangka awal. Folder uploads/absensi disediakan untuk foto. Ubah password awal setelah login.
